# Crazy Fruit Blade Winner - Analisis Monetisasi & Panduan Bot

Panduan teknis dan catatan monetisasi untuk game **Crazy Fruit Blade Winner**.

- **Nama Game**: Crazy Fruit Blade Winner
- **Package ID**: `com.starlightgame.crazyfruitbladewinner`
- **Developer / Perusahaan**: ACM PROJECTS & AUTOMATION LTD / Elias Galvin
- **Kategori**: Fruit Blade / Slicing
- **Skrip Bot**: `crazy-fruit-blade-winner/crazy_fruit_blade_guardian_bot.py`

---

## 1. Catatan Penarikan & Analisis Monetisasi

| Parameter | Keterangan |
|---|---|
| **Instalasi Pertama** | Sekitar Rp200 per hari di awal, tetapi langsung turun setelahnya; lumayan, tetapi rawan block iklan. |
| **Instalasi Kedua** | **Tetap DANA dan awalnya bisa capai Rp15.000.** |
| **Iklan Slot** | Lumayan, tetapi rawan blokir iklan. |
| **Rekomendasi Instalasi** | **Rekomendasi menengah.** Posisi prioritas 5 (di atas Color Power Pop). |
| **Metode Pencairan** | DANA / Saldo e-wallet. |

## 2. Fitur Bot Guardian (`crazy_fruit_blade_guardian_bot.py`)

Clone dari `fruit-blade-pop-crush/` untuk game **Crazy Fruit Blade Winner**.

- Package Android: `com.starlightgame.crazyfruitbladewinner`
- Bot utama: `crazy_fruit_blade_guardian_bot.py`
- Jalankan: `./run_crazy_fruit_blade_guardian_bot.sh`
- Stop: `./stop_crazy_fruit_blade_guardian_bot.sh`
- Log: `/Users/macbookair/crazy_fruit_blade_guardian_bot.log`

Contoh:

```bash
cd /Users/macbookair/android-game-bots/crazy-fruit-blade-winner
./run_crazy_fruit_blade_guardian_bot.sh
```
