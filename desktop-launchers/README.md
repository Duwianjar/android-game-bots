# Desktop Launchers

Shortcut `.command` yang sebelumnya berada di Desktop untuk menjalankan bot Android di repo ini.

Launcher yang disalin:

- `1 Buka Dua SCRCPY.command`
- `2 Magic Ocean + Bot.command`
- `3 Woodland + Bot.command`
- `4 Stop Semua Bot.command`
- `5 Bot Bergantian Magic-Woodland.command`
- `6 Stop Bot Bergantian.command`
- `Bus Jam + Bot.command`

Catatan: file ini tetap memakai path lokal `/Users/macbookair/android-game-bots/...`, sesuai lokasi repo di Mac ini.
